1. Философия проекта
Видение
«Ключ» — это игровая экосистема, объединяющая реальные игрушки из игровых автоматов с короткими интерактивными приключениями.
Игрушка не является наградой.
Игрушка является Ключом, открывающим новое приключение.
Каждая выигранная игрушка запускает новую историю продолжительностью около одной минуты.
Во время приключения игрок принимает решения, получает уникальные находки и постепенно раскрывает тайны большого мира.
Главная задача проекта — сделать так, чтобы каждая новая игрушка продолжала приключение, а не просто увеличивала коллекцию.

Основные правила проекта
Игрушка — это Ключ.
Один Ключ = одна история.
Средняя продолжительность истории — 30–60 секунд.
История всегда начинается с загадки.
В игре нет неправильных выборов — есть разные последствия.
Любая история заканчивается новой интригой.
После каждой истории игрок получает находку.
Любая находка может пригодиться позже.
Мир постепенно открывается с каждым новым Ключом.

4. Игровые механики
Утверждено:
Ключ открывает только одну историю.
Истории построены как интерактивные мини-квесты.
Игрок управляет только выбором действий.
Истории полностью описываются JSON.
StoryEngine исполняет историю.
История не зашивается в код.
Каждый выбор имеет последствия.
Некоторые пути требуют нового Ключа.
Некоторые предметы понадобятся позже.

5. Коллекция находок
Рабочее название:
Коллекция находок
Все найденные предметы сохраняются навсегда.
Большинство предметов сначала кажутся бесполезными.
Позже они начинают использоваться в новых историях.
Примеры:
Старый жетон
Болт
Повреждённый робот
Батарейка
Кассета

9. Экономика проекта
Игрушка является входным билетом в новую историю.
Игрушка не расходуется внутри игры.
Каждый новый Ключ открывает новое приключение.
В дальнейшем возможны:
обмен игрушек;
реальные призы;
редкие события;
сезонные истории.

10. Техническая архитектура
Проект разделён на три независимые системы
StoryEngine
Универсальный движок исполнения интерактивных историй.
Не знает ничего о проекте «Ключ».

StoryFactory
Отдельный проект.
Автоматическая фабрика создания историй.
Находится в стадии проектирования.

Проект «Ключ»
Использует StoryEngine и контент StoryFactory.
Содержит:
миры;
истории;
изображения;
предметы;
QR;
игровые механики.

Архитектурный статус
StoryEngine считается стабильным.
Дальнейшие изменения допускаются только при наличии реальной необходимости, выявленной во время разработки контента.

12. Правила разработки
Архитектура StoryEngine заморожена.
Новые возможности добавляются через контент, а не через изменение движка.
Любая история должна работать без изменения кода StoryEngine.
Любая новая игра должна подключаться как отдельный проект.
Сначала создаётся рабочий прототип, затем расширяется функциональность.
