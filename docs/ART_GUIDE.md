# ART GUIDE — История Neo City (первая история)

Техническое задание для художника.

Документ описывает финальные требования к иллюстрациям сцен истории **Neo City**.
Все будущие изображения рисуются **строго под существующие hotspot**.
Архитектура игры после утверждения этого документа **не меняется**.

---

## Общие правила

### Система координат

- Hotspot задаются в координатах области **иллюстрации**.
- `X = 0..100` — слева направо.
- `Y = 0..100` — сверху вниз.
- `Width` и `Height` — размер области в процентах области иллюстрации.
- `Rotation` — угол поворота hotspot в градусах.
- `Scale` — масштаб hotspot (1 = 100%).

Источник координат: файлы Scene Layout

```
projects/key/stories/neo_city/layouts/<sceneId>.layout.json
```

Проверка в редакторе:

```
/story/key/neo_city/<sceneId>?storyEditor=1
```

### Размер изображения

| Параметр | Значение |
|----------|----------|
| Формат файла | WebP |
| Соотношение сторон | **25 : 12** (ширина : высота) |
| Рекомендуемый размер | **1000 × 480 px** |
| Допустимый размер (ретина) | **2000 × 960 px** |
| Цветовой профиль | sRGB |
| Ориентация | Альбомная (ширина больше высоты) |

Изображение занимает область **иллюстрации** экрана истории.
Область иллюстрации на экране: `X = 0..100`, `Y = 10..58` (в координатах экрана).

Файлы фона сцен:

### Safe Zone

**Safe Zone (экран, координаты 0..100):**

| Зона | X | Y | W | H | Назначение |
|------|---|---|---|---|------------|
| Верхняя панель | 0 | 0 | 100 | 10 | HUD игрока |
| Область иллюстрации | 0 | 10 | 100 | 48 | **Место для вашего изображения** |
| Название сцены | 0 | 58 | 100 | 6 | Заголовок |
| Текст | 4 | 64 | 92 | 14 | Текст истории |
| Действия | 4 | 78 | 92 | 22 | Кнопки выбора |

**Запрещённая зона для важных объектов (экран):** `Y = 58..100`

Нижние 42% экрана заняты интерфейсом. Важные элементы сюда **не помещать**.

**Safe Zone (внутри иллюстрации, координаты 0..100):**

| Зона | X | Y | W | H | Правило |
|------|---|---|---|---|---------|
| Верхний безопасный отступ | 0 | 0 | 100 | 8 | Не размещать ключевые объекты у самого верхнего края |
| Нижний безопасный отступ | 0 | 88 | 100 | 12 | Не размещать ключевые объекты у нижнего края иллюстрации |
| Боковые отступы | 0 | 0 | 4 | 100 | Левый отступ |
| Боковые отступы | 96 | 0 | 4 | 100 | Правый отступ |

**Safe Padding (внутри hotspot):**

Отступ **2%** от границы hotspot внутрь. Критически важная графика объекта должна полностью помещаться внутрь области с учётом Safe Padding.

### Правило заморозки (после утверждения)

После утверждения данного документа **запрещается менять:**

- координаты hotspot;
- размеры hotspot;
- Safe Zone;
- Rotation;
- Scale.

**Меняются только изображения.**

Художник подгоняет графику под hotspot, а не наоборот.

## Scene 001 — Комната

**ID сцены:** `scene_001`
**Название:** Комната
**Файл фона:** `001_room.webp`
**Размер изображения:** 1000 × 480 px (25:12)
**Текст сцены:** «Ты просыпаешься в незнакомой комнате. На столе лежит коробка — она слегка подрагивает и мягко светится.»

### Safe Zone для сцены

Важные элементы не должны попадать в Safe Zone экрана (`Y = 58..100`).
Коробка расположена в нижней части иллюстрации, но **выше** нижнего безопасного отступа иллюстрации (`Y < 88`).

### Hotspot: box

| Параметр | Значение |
|----------|----------|
| id | `box` |
| тип | `hotspot` |
| label | Коробка |
| shape | `rectangle` |
| X | 38 |
| Y | 58 |
| Width | 22 |
| Height | 18 |
| Rotation | 0 |
| Scale | 1 |
| Safe Padding | 2 |
| action | navigate |
| animation | pulse, glow, sway |
| primary | true |

#### Что должен нарисовать художник

Под hotspot `box` должна располагаться **крышка коробки**.

Требования:

- Вся коробка должна быть **полностью видна** внутри hotspot.
- Крышка — главный визуальный акцент сцены.
- Коробка слегка светится (сюжетный элемент).
- Коробка стоит на столе или поверхности комнаты.
- Важные элементы коробки не должны попадать в Safe Zone.
- Не обрезать коробку по краям hotspot.
- Внутри hotspot с Safe Padding 2% вся графика коробки должна быть читаемой.

## Scene 003 — Механический зверёк

**ID сцены:** `scene_003`
**Название:** Механический зверёк
**Файл фона:** `003_robot.webp`
**Размер изображения:** 1000 × 480 px (25:12)
**Текст сцены:** «Из коробки появляется механический зверёк. Его глаза тускло мерцают.»

### Safe Zone для сцены

Робот занимает центральную часть иллюстрации. Голова и глаза — в верхней половине hotspot. Не выносить глаза за пределы hotspot.

### Hotspot: robot

| Параметр | Значение |
|----------|----------|
| id | `robot` |
| тип | `npc` |
| label | Зверёк |
| shape | `rectangle` |
| X | 28 |
| Y | 32 |
| Width | 44 |
| Height | 48 |
| Rotation | 0 |
| Scale | 1 |
| Safe Padding | 2 |
| action | dialog |
| animation | sway, glow, blink, float |
| primary | true |

#### Что должен нарисовать художник

Под hotspot `robot` должны находиться:

- **голова**
- **глаза**
- **верхняя часть корпуса**

Требования:

- Именно **глаза** должны быть чётко видны и расположены в верхней трети hotspot.
- Глаза предназначены для будущей **анимации включения** (мерцание, пробуждение).
- Глаза должны быть контрастными и читаемыми при размере hotspot.
- Голова и плечи/верх корпуса полностью внутри hotspot.
- Робот появляется из коробки — нижняя часть тела может уходить в коробку за пределы hotspot, но голова и глаза обязаны быть внутри.
- Не размещать глаза в Safe Zone иллюстрации у верхнего или нижнего края.
- Важные элементы лица не должны попадать в Safe Zone экрана.

## Scene 007 — Пробуждение

**ID сцены:** `scene_007`
**Название:** Пробуждение
**Файл фона:** `003_robot.webp`

**Текст сцены:** «Ты возвращаешься с батарейкой и вставляешь её в зверька. Он оживает!»

**Визуальный эффект сцены:** `power-on` — анимация включения робота.

### Safe Zone для сцены

Жетон и батарейный отсек — в центральной нижней части робота. Не перекрывать область popup награды на экране.

### Hotspot: token

| Y | 60 |
| Width | 16 |
| Height | 14 |
| Rotation | 0 |
| Scale | 1 |
| Safe Padding | 2 |
| action | navigate |
| primary | true |

#### Что должен нарисовать художник

Под hotspot `token` должен находиться **жетон**.

Требования:

- Жетон полностью виден внутри hotspot.
- Жетон находится в лапе робота, на вытянутой лапе или перед роботом.
- Жетон — небольшой, но читаемый объект.
- Робот оживлён (глаза светятся) — это фон сцены, не hotspot.
- Жетон не должен попадать в Safe Zone.
- Внутри hotspot только жетон как кликабельный объект.

## Проверка перед сдачей

1. Откройте сцену в Story Editor: `/story/key/neo_city/<sceneId>?storyEditor=1`
2. Убедитесь, что каждый объект полностью попадает в свой hotspot.
3. Убедитесь, что важные элементы не попадают в Safe Zone.
4. Убедитесь, что файл WebP имеет соотношение 25:12.
5. Пройдите сцену в игре без редактора и проверьте совпадение клика с графикой.
